# ChargeDoctor

## 概要

ChargeDoctorは、Android端末のバッテリー状態や充電状況を確認するために開発したAndroidアプリケーションです。
充電ケーブルの状態を診断し、診断結果を「良好」または「注意」として分かりやすく表示します。

## 主な機能

* バッテリーおよび充電状態の確認
* 充電ケーブルの診断
* 診断結果（良好・注意）の表示
* 充電が切断された回数の表示
* ケーブル名を付けた診断結果の保存
* 過去の診断履歴の確認
* 文字サイズの変更
* 表示言語の変更

## 使用技術

* Java
* Android Studio
* XML
* SharedPreferences
* Git / GitHub

## 工夫した点

診断結果を利用者が簡単に理解できるように、結果を分かりやすく表示する画面を作成しました。
また、ケーブル名と診断結果を保存し、過去の履歴を確認できるようにしました。

## 開発目的

Androidアプリケーション開発の学習を目的として、画面設計、データ保存、画面遷移などの機能を実装しました。
